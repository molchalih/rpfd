# The numbers tools/docgate/docgate.sh checks itself against. They are
# measurements and one declaration, not preferences, and they are here rather
# than in the script so that moving one is a line in a diff a reviewer can argue
# with.
#
#   claims  the fewest path claims the extractor may find before the gate stops
#           believing itself. Lowering this is a claim about the documentation
#           and needs the measurement that supports it — the usual cause is the
#           script, not the docs.
#
#   bytes   the tracked Markdown surface, in bytes, measured by
#             git ls-files -z -- '*.md' | xargs -0 cat | wc -c
#           **Zero slack, deliberately.** The gate fails both above and below
#           this number, so it is a ratchet rather than a ceiling: every
#           documentation change is expected to move this line, and that is the
#           point. Headroom would be spent silently by whatever grew next, and
#           an unreviewed byte is exactly what a budget exists to prevent —
#           a ceiling nobody has looked at is not a measurement of anything.
#           The cost is one line in the diff of every documentation change,
#           which is the same line the change already owes a reviewer.
#
#   roots   the top-level entries of this repository that a command line inside
#           a fenced block may be rooted at. Declared here rather than derived
#           from `git ls-files`, because derived meant a renamed directory
#           stopped being a subject instead of being reported: every command
#           line naming `tools/` went unread the moment `tools/` was gone. The
#           gate fails when one of these stops naming a tracked directory, so
#           the rename is caught from both sides. A new top-level directory that
#           command lines name is added here in the change that adds it.
#
# Measured on the settled tree with `./tools/docgate/docgate.sh measure`:
#   claims 113  bytes 98702  citations 106 (n/a)  excused 25 (22.1%)
#
# The `bytes` line moves down from 105132, and the 6430 bytes it gives back are
# a decision reversed rather than prose trimmed. `docs/decisions/INDEX.md` was
# tracked for one round — 7585 bytes — so that the `DR-NNN` citations in tracked
# code, scripts and workflows resolved for a cloner. It is untracked again: the
# whole design record is working-tree material, with no exception, and the pages
# that described the index as shipping have lost the paragraphs and table rows
# that said so. `README.md` gains the plainer statement in their place — that a
# `DR-NNN` in a clone names a local document the reader does not have — which is
# why the fall is smaller than the page that left.
#
# The citation check finds 106 identifiers and can resolve none of them, so it
# reports `n/a — no yield` and counts in neither direction. A permanent red on a
# decision the repository made deliberately would be noise, and a green would
# claim the citations had been followed when none was.
#
# `docs` came off the `roots` line in the same change: nothing under it is
# tracked any more, and a declared root naming no tracked directory is a failure
# by design. No fenced command line in any tracked page was rooted there, so
# nothing stopped being read as a claim.
#
# `claims` stays at 75 and is not moved: the extractor yields 113 against it, so
# the floor is doing what it is for — a tripwire under the extractor, tripped
# when shape_ok() or the fence split stops matching. Raising it to sit just under
# today's yield would convert it into a second byte budget on a number that moves
# for reasons nobody reviews, and it is the low side of it that carries meaning.
claims 75
bytes 98702
roots .cargo .githooks .github clients crates fixtures fuzz tools
